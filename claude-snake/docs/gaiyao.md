# 概要设计

## 1. 系统概述

基于浏览器 + Node.js 的贪吃蛇小游戏。用户通过浏览器访问 `localhost:3031` 即可游玩。
后端仅做静态文件托管，所有游戏逻辑在浏览器端 JavaScript 中运行。

## 2. 功能需求

| 功能 | 描述 |
|------|------|
| 游戏画布 | 左侧 Canvas 区域，绘制网格、蛇身、食物 |
| 开始游戏 | 右侧按钮，点击后初始化蛇和食物，启动游戏循环 |
| 结束游戏 | 右侧按钮，停止当前游戏，回到初始状态 |
| 方向控制 | 键盘 ↑↓←→ 控制蛇头方向，不可反向 |
| 暂停/继续 | 空格键切换暂停状态，暂停时画布中央显示 "pausing" |
| 操作说明 | 右侧区域展示键盘操作指引 |
| 碰撞检测 | 蛇头撞墙或撞自身 → 游戏结束 |
| 食物生成 | 蛇头吃到食物 → 蛇身增长 + 分数增加 + 随机刷新食物 |

## 3. 系统架构

```
┌──────────────┐      HTTP      ┌──────────────────────┐
│   浏览器      │ ◄──────────► │   Node.js Server      │
│  (index.html) │   静态文件     │   (Express, :3031)    │
└──────┬───────┘                └──────────────────────┘
       │
       │ 游戏逻辑全在前端
       ▼
┌──────────────────────────────────────┐
│  Game Engine (script.js)              │
│  ┌─────────┐  ┌────────┐  ┌───────┐  │
│  │ Canvas   │  │ State  │  │ Input │  │
│  │ Renderer │  │Machine │  │Handler│  │
│  └─────────┘  └────────┘  └───────┘  │
└──────────────────────────────────────┘
```

## 4. 页面布局

整体居中，水平两栏：

```
┌─────────────────────────────────────────────────┐
│             贪吃蛇游戏（标题）                      │
├──────────────────────┬──────────────────────────┤
│                      │  [开始游戏]               │
│   游戏画布           │  [结束游戏]               │
│   (Canvas)           │                          │
│                      │  操作说明：               │
│                      │  ↑↓←→ 移动              │
│                      │  空格 暂停/继续           │
└──────────────────────┴──────────────────────────┘
```

- 整体 content 区域 `max-width: 800px`，居中
- 左侧画布 400×400，深色背景，网格线
- 右侧面板 200px，垂直排列按钮和文字

## 5. 游戏状态机

```
┌───────┐  点击开始   ┌─────────┐  空格   ┌─────────┐
│ idle  │ ────────►  │ playing │ ────►  │ paused  │
└───────┘            └─────────┘        └─────────┘
   ▲                   │    │              │
   │   撞墙/撞身        │    │  点击结束     │  空格
   │   ── 游戏结束 ────►│    └─────────────┘
   │                    ▼
   │               ┌──────────┐
   └────────────── │ gameover │
                    └──────────┘
```
