# 记账本概要设计文档

## 1. 项目目标

开发一款轻量级网页版记账工具，帮助用户记录日常收入与支出，并通过统计图表直观了解财务状况。

## 2. 技术选型

| 层级 | 技术 | 选型理由 |
|---|---|---|
| 开发语言 | Python 3.10+ | 语法简洁，生态丰富，适合快速开发 |
| Web 框架 | Streamlit | 无需 HTML/CSS/JS，纯 Python 即可构建交互式 Web 界面 |
| 数据库 | sqlite3 | Python 内置，零配置，单文件部署，满足个人记账场景 |
| 图表展示 | Streamlit 内置图表 | 无需引入额外图表库，降低复杂度 |

## 3. 系统架构

```
+-----------------+        +-----------------------------+        +-----------------+
|   用户浏览器     |  <--->  |   Streamlit 应用            |  <--->  |   sqlite3       |
|                 |  HTTP   |   app.py + components.py    |  SQL    |   数据库文件     |
+-----------------+        +-----------------------------+        +-----------------+
                                    |        |
                          models.py |        | database.py
                                    |        |
                                    v        v
                               utils.py   data/accounting.db
```

整个系统采用 **服务端渲染 + 本地数据库** 架构：

- `app.py` 作为入口，组合页面布局。
- `components.py` 负责所有 UI 组件渲染。
- `database.py` 负责与 sqlite3 交互。
- `models.py` 和 `utils.py` 提供数据模型与通用工具。

## 4. 功能模块

### 4.1 记账模块

- 选择类型：收入 / 支出
- 输入金额
- 选择分类
- 选择日期
- 填写备注
- 提交保存

### 4.2 明细模块

- 按时间倒序展示记录
- 支持删除单条记录
- 支持按月份筛选

### 4.3 统计模块

- 月度概览：收入总额、支出总额、结余
- 分类统计：支出按分类占比
- 趋势统计：近 6 个月收支趋势

## 6. 数据流

1. 用户打开页面，Streamlit 加载并渲染界面。
2. 用户填写表单并点击保存。
3. Streamlit 调用 `database.py` 中的写入函数。
4. 数据存入 sqlite3 数据库。
5. 页面自动重跑，重新读取数据并更新统计与列表。

## 7. 非功能需求

- **易用性**：界面简洁，操作步骤少。
- **可靠性**：数据持久化到本地数据库，避免丢失。
- **可维护性**：模块划分清晰，职责单一。
- **可扩展性**：后续可方便增加导入导出、预算提醒等功能。

## 8. 部署方式

- 本地运行：`streamlit run app.py`
- 服务器部署：Streamlit Community Cloud / Railway / Render / 自有 VPS

## 9. 风险与限制

- Streamlit 每次交互会重跑脚本，需合理使用缓存和表单。
- UI 自定义能力有限，不适合复杂界面需求。
- 默认无用户认证，数据为单用户本地使用。
