# 《打砖块》（Breakout）游戏设计文档

## 1. 项目概述

本项目是一款运行在浏览器中的单人打砖块小游戏。玩家控制屏幕底部的挡板反弹小球，击碎关卡中的全部砖块以获得胜利；小球从底部离开游戏区域时会损失生命。

### 设计目标

- 上手简单：只需左右移动挡板。
- 单局节奏紧凑：一局约 2～5 分钟。
- 反馈清晰：碰撞、得分、失误和通关都应有即时视觉反馈。
- 具备重复游玩性：通过多关卡、砖块布局和道具变化提供挑战。

### 默认定位（可调整）

- 平台：桌面浏览器，兼容键盘操作。
- 模式：单人闯关。
- 视觉方向：简洁的街机风格。
- 初始生命：3 条。

## 2. 核心玩法

游戏区域上方排列砖块，底部为可水平移动的挡板。小球在区域内持续运动：

1. 小球撞到墙壁时按相应方向反弹。
2. 小球撞到挡板时向上反弹；撞击挡板的位置会影响反弹方向。
3. 小球撞到砖块时反弹，并使砖块受损或消失。
4. 清除当前关卡全部可破坏砖块后，进入下一关或判定通关。
5. 小球越过底部边界时，玩家失去一条生命并重新发球。
6. 生命归零后，游戏结束。

## 3. 操作设计

| 场景 | 操作 | 行为 |
| --- | --- | --- |
| 游戏中 | 左方向键 / A | 挡板向左移动 |
| 游戏中 | 右方向键 / D | 挡板向右移动 |
| 发球前 | 空格键 | 发射小球 |
| 任意进行中状态 | P / Esc | 暂停或继续 |
| 结算界面 | Enter / 点击按钮 | 重新开始或进入下一关 |

后续可补充鼠标或触摸拖动操作，便于移动端游玩。

## 4. 游戏对象与规则

### 4.1 挡板

- 位于游戏区域底部，不能离开左右边界。
- 初始宽度适中，保证新玩家能稳定接球。
- 挡板中心接球时，小球近似垂直向上反弹；越靠近两侧接球，水平分量越大。
- 获得“加长挡板”道具后，挡板宽度暂时增加。

### 4.2 小球

- 每次发球从挡板上方开始。
- 始终保持最小垂直速度，避免出现几乎水平、长期无法结束的运动轨迹。
- 速度可随关卡或连击逐步提升，并设置上限以保证可操作性。
- 多球道具会额外生成小球；场上仍有任意小球时游戏继续。

### 4.3 砖块

基础砖块分为以下类型：

| 类型 | 耐久 | 分数 | 规则 |
| --- | ---: | ---: | --- |
| 普通砖 | 1 | 100 | 一次击中即消失 |
| 坚固砖 | 2 | 200 | 第一次击中改变外观，第二次消失 |
| 金属砖 | 不可破坏 | 0 | 反弹小球，不计入通关所需清除数 |
| 道具砖 | 1 | 100 | 消失时概率掉落道具 |

### 4.4 道具

道具从被击碎的道具砖处向下落，挡板接到后立即生效。默认道具池如下：

| 道具 | 效果 | 持续时间 |
| --- | --- | --- |
| 扩展 | 挡板变宽 | 15 秒 |
| 多球 | 生成 2 个额外小球 | 直到小球失去 |
| 减速 | 小球速度降低 | 10 秒 |
| 穿透 | 小球命中砖块时不反弹 | 8 秒 |
| 额外生命 | 增加 1 条生命 | 立即生效 |

负面道具不纳入首版，避免增加学习成本；后续可作为高难度关卡机制引入。

## 5. 关卡设计

首版建议提供 3 个关卡，遵循由易到难的节奏。

| 关卡 | 布局与机制 | 目标 |
| --- | --- | --- |
| 1 | 矩形普通砖阵列，少量道具砖 | 熟悉反弹和操作 |
| 2 | 加入坚固砖，砖块排布出现缺口 | 练习控制反弹角度 |
| 3 | 加入金属砖形成障碍，部分砖块位置更分散 | 考验路线规划与稳定接球 |

关卡完成后显示本关得分、剩余生命和“下一关”入口。通过最后一关后显示总分与重新挑战入口。

## 6. 数值与计分

### 初始数值

- 初始生命：3。
- 初始小球速度：中等。
- 每关基础速度提升：约 8%～12%。
- 道具砖掉落概率：约 20%。

### 得分规则

- 普通砖：100 分。
- 坚固砖：每次有效命中 100 分，击碎合计 200 分。
- 道具砖：100 分，接住道具额外 50 分。
- 清关奖励：`剩余生命 × 500` 分。
- 连续命中不作为首版的计分条件，避免规则不透明；可在后续版本加入连击倍率。

## 7. 状态流程

```text
加载游戏
  → 开始界面
  → 关卡准备（小球附着挡板）
  → 游戏进行中
      ├─ 小球落底且仍有生命 → 关卡准备
      ├─ 清除全部目标砖块 → 关卡结算 → 下一关
      └─ 生命归零 → 游戏结束
最后一关结算 → 通关界面 → 重新开始
```

暂停状态可从“关卡准备”和“游戏进行中”进入；暂停时所有小球、道具和计时效果停止。

## 8. 界面与反馈

### 游戏内布局

- 顶部信息栏：当前关卡、分数、生命数量、暂停按钮。
- 中央游戏区：砖块、小球、道具及挡板。
- 底部提示区：首次进入时提示移动和发球操作。

### 视觉反馈

- 砖块受击时短暂闪烁；坚固砖显示耐久变化。
- 小球碰撞时出现轻量粒子或缩放效果。
- 获得道具时显示名称和剩余时间。
- 失球、通关、游戏结束时展示明确的遮罩层提示。

### 音效（可选）

- 墙壁、挡板、砖块采用不同的短音效。
- 获得道具、失球和通关使用独立提示音。
- 首版可预留静音开关；若无音频资源，不影响核心玩法。

## 9. 边界与异常规则

- 小球同时接触多个对象时，优先处理砖块命中，再依据碰撞方向修正速度。
- 挡板两端接球仍需保证小球向上运动，避免向下反弹。
- 多球状态下，最后一个小球离场才判定失球。
- 金属砖不会阻挡通关判定。
- 生命达到上限时，额外生命道具可转化为分数；首版上限建议为 5 条。

## 10. 首版验收标准

- 能从开始界面进入游戏，并通过键盘控制挡板。
- 小球可正确与墙壁、挡板、普通砖和坚固砖发生碰撞。
- 小球落底会扣除生命并重新发球。
- 清除可破坏砖块可完成关卡，生命耗尽会进入游戏结束界面。
- 分数、生命和关卡信息会实时更新。
- 暂停、继续和重新开始可正常使用。

## 11. 后续扩展方向

- 关卡选择与本地最高分记录。
- 随机生成砖块布局。
- Boss 砖块、移动砖块与限时挑战。
- 移动端触摸控制与响应式布局。
- 主题皮肤、背景音乐与无障碍设置。
