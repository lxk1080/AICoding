# AI 行业资讯来源策略（V1）

本文件为 `ai-wechat-article` 提供来源优先级和判断原则。V1 不维护封闭白名单；应根据来源的原始性、编辑规范、作者身份、发布日期与可验证性进行判断。

## P0：官方与一手来源

优先用于确认事件本身、发布内容、官方立场和原始技术资料。

- 公司、实验室、产品或项目的官方网站、新闻室、官方博客、官方文档。
- 官方 GitHub 组织、仓库、Release、README、模型卡与 Issue/公告（仅限可确认官方归属的内容）。
- 官方论文页、预印本作者页、项目主页、发布会文字稿或公开视频。
- 监管机构、交易所、法院、政府部门和公司投资者关系页面的原始披露。
- 经可靠方式确认归属的官方社交账号；社媒更适合确认公告和时间线，重大事实应尽量回到官网或原始文件。

注意：P0 能证明“发布者说过/发布过什么”，不天然证明性能宣传、市场影响或争议结论。

## P1：高质量行业资讯与机构

用于独立报道、背景补足、交叉验证与行业语境。优先原始报道和有署名、发布日期、编辑责任的内容。

- 权威通讯社与主流财经、科技媒体。
- 具有长期专业编辑流程的 AI、开发者、开源和学术技术媒体。
- 研究机构、大学、行业协会、咨询机构发布的可追溯报告或数据。

判断重点：报道是否引用了原始材料或可识别的消息来源；是否是转载、聚合、软文或没有署名的内容；是否与事件时间相符。

## P2：搜索补充来源

仅在 P0 和 P1 无法补足必要上下文时使用。可用于发现线索、解释有限背景或引用明确归因的讨论。

- 搜索结果中排序靠前且具备清晰作者、时间与出处的垂直媒体文章。
- 可信组织的整理文章、技术社区讨论或二次解读。

不要把排名、浏览量或转发量视为可信度。论坛帖子、匿名爆料、无法验证的截图、搜索摘要和无出处转载不能单独支撑关键事实。

## 关键事实的最低门槛

| 事项 | 推荐证据 |
| --- | --- |
| 产品/模型发布、官方功能、开源仓库变动 | P0 |
| 融资金额、财报、收购、监管处罚、法律结论 | P0，或两家独立 P1 |
| 性能、用户数、收入、市场份额 | 原始测试/披露优先；否则明确数据来源、方法和局限 |
| 传闻、争议、事故、人员变化 | P0 回应或两家独立 P1；未证实则不写成事实 |

## 独立性与时效性

两篇引用同一篇新闻稿、同一匿名消息或彼此转载的文章不构成独立交叉验证。动态事件优先使用最新的原始资料，并在文章中标注信息检索截止日期。
